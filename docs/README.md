# Projekt-Unterlagen

Hier liegt alles, was zum Projekt gehört, aber kein Code ist: Notizen, Ideen,
Entscheidungen, Bilder.

## Was liegt wo

| Datei | Wofür |
|---|---|
| [`uebersicht.md`](uebersicht.md) | Worum geht es überhaupt — Ziel, Umfang, offene Fragen |
| [`todo.md`](todo.md) | Offene Punkte als Checkliste |
| [`entscheidungen.md`](entscheidungen.md) | Was wurde entschieden und warum |
| [`notizen.md`](notizen.md) | Freitext für alles, was noch keinen Platz hat |
| [`assets/`](assets/) | Bilder, PDFs, Screenshots, Skizzen |

## Hinweise

- Neue Themen einfach als weitere `.md`-Datei hier anlegen und oben in der
  Tabelle eintragen.
- Dateien aus `assets/` lassen sich in Markdown so einbinden:
  `![Beschreibung](assets/dateiname.png)`
